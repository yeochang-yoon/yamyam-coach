# 냠냠코치 · Java 콘솔

Java 기본 문법과 객체지향, 컬렉션, 파일 입출력을 익힌 뒤 만든 냠냠코치의 첫 버전입니다. 콘솔에서 음식을 찾고 먹은 양을 입력하면 한 끼와 하루의 영양 섭취량을 확인할 수 있습니다. 회원과 식단은 Gson으로 JSON 파일에 저장합니다.

## 주요 기능

- 회원가입, 로그인·로그아웃, 본인 프로필 조회·수정·탈퇴
- 음식 이름과 식품코드로 검색하고 음식 기준에 맞춰 g 또는 mL로 섭취량 입력
- 식단 작성, 내 식단 전체 목록과 ID별 상세 조회, 수정·삭제
- 한 끼 또는 날짜별 열량·탄수화물·단백질·지방 합계 확인

회원은 이름과 키, 몸무게, 질환 정보를 관리할 수 있습니다. 탈퇴하면 본인 식단도 함께 삭제됩니다. 영양값은 음식의 기준량과 섭취량을 이용해 조회할 때 계산합니다.

## 실행

Java 11을 기준으로 작성했으며 JDK 11 이상에서 Maven Wrapper로 실행합니다. 첫 빌드 때 Maven이 `pom.xml`에 등록된 Gson과 테스트 라이브러리를 내려받습니다.

```powershell
cd pjt1
.\mvnw.cmd compile exec:java
```

macOS와 Linux에서는 `sh ./mvnw compile exec:java`를 실행합니다.

첫 실행에서는 아래 계정으로 로그인할 수 있습니다. 각 계정에는 2025년 4월 21일부터 27일까지 아침·점심·저녁 기록 21건이 들어 있습니다.

| 아이디 | 비밀번호 |
| --- | --- |
| `demo01` | `DemoMeal01!` |
| `demo02` | `DemoMeal02!` |

로그인 후 `5 식단 목록`에서 기록 ID를 확인하고 `6 상세`에서 음식과 한 끼 영양 합계를 볼 수 있습니다. `9 하루 분석`에서 `2025-04-21`을 입력하면 당일 기록을 합산합니다. 새 기록은 `3 음식 검색`에서 식품코드를 확인한 뒤 `4 식단 작성`에서 추가합니다.

## 데이터와 저장

- [foods.json](src/main/resources/data/foods.json)은 음식 5,789건의 이름, 식품코드, 100g 또는 100mL 기준 영양값을 담습니다. 식품의약품안전처와 농촌진흥청의 음식 영양성분 자료를 바탕으로 정리했습니다.
- [users.json](src/main/resources/data/users.json)과 [diet-data.json](src/main/resources/data/diet-data.json)은 첫 실행에 사용하는 가상 회원과 식단입니다.
- 회원이나 식단이 바뀌면 `pjt1/runtime/state.json`에 저장됩니다. 이후 실행에서는 이 파일에서 마지막 상태를 불러옵니다. 비밀번호는 PBKDF2-HMAC-SHA256 해시로 저장합니다.

## 구현 방식

| 구성 | 담당하는 일 |
| --- | --- |
| `console` | 키보드 입력을 받아 메뉴를 실행하고 식단과 분석 결과를 보여줍니다. |
| `service` | 음식 목록을 순회해 식품코드나 이름을 확인하고, 회원·식단 입력을 검증합니다. |
| `domain` | 일반 Java 클래스와 생성자, getter로 회원·음식·식단·영양값을 표현합니다. |
| `repository` | 회원과 식단을 ID별로 보관하며, Gson으로 JSON을 읽고 저장합니다. |

식단에는 식품코드와 섭취량을 기록합니다. 상세 조회나 하루 분석을 실행하면 음식별 기준 영양값에 `섭취량 ÷ 기준량`을 곱하고 항목별로 더합니다. 예를 들어 100g에 172kcal인 현미밥을 150g 먹으면 258kcal로 집계합니다. 변경한 식단은 다음 분석에 바로 반영됩니다.

## 검증

자동 테스트는 `.\mvnw.cmd test` 또는 `sh ./mvnw test`로 실행합니다. 초기 데이터 로딩, 재실행 후 회원·식단 복원, 회원별 식단 접근 제한, g·mL 환산, 손상된 파일 보존을 확인합니다. 콘솔에서 직접 확인할 때는 [수동 테스트 입력 순서](콘솔-수동-테스트.txt)를 참고합니다.
