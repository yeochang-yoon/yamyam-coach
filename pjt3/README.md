# 냠냠코치 · 브라우저 식단 기록

Java 콘솔에서 제공하던 음식 검색, 식단 기록, 날짜별 영양 분석을 브라우저에서 사용할 수 있게 만들었습니다. HTML과 CSS로 입력 폼과 목록을 구성하고, JavaScript의 함수·반복문·DOM 이벤트로 PJT2의 접두어 검색과 음식별 섭취 열량 순위를 구현했습니다. 회원과 식단 변경은 브라우저에 저장합니다.

## 주요 기능

- 회원가입, 로그인과 로그아웃, 프로필 조회·수정과 회원 탈퇴
- 이름에 들어 있는 단어나 식품코드로 음식 검색, 이름 시작 부분 검색
- 섭취량을 g 또는 mL로 입력해 식단 작성, 전체 목록·상세 조회, 수정·삭제
- 하루의 열량·탄수화물·단백질·지방 합계와 음식별 섭취 열량 순위

## 실행

Python 3.10 이상에서 정적 서버를 실행합니다. 이 서버는 HTML, CSS, JavaScript와 JSON을 제공하고, 입력 처리와 영양 계산은 브라우저에서 실행합니다.

```powershell
cd pjt3
python serve.py
```

기본 주소는 `http://127.0.0.1:8033`입니다. 첫 화면의 **로그인 정보 채우기** 버튼으로 데모 계정을 입력할 수 있습니다. 직접 입력하려면 `demo01` / `DemoMeal01!` 또는 `demo02` / `DemoMeal02!`를 사용합니다. 각 계정에 2025년 4월 21~27일의 아침·점심·저녁 식단 21건이 있습니다.

## 소스와 저장

| 파일 | 역할 |
| --- | --- |
| `web/index.html`, `web/style.css` | 회원·식단 HTML 폼, Bootstrap과 반응형 스타일 |
| `web/js/app.js` | 버튼과 폼 이벤트를 연결하고 DOM에 목록과 분석을 표시 |
| `web/js/domain.js` | 이름 검색, 입력 검증, g·mL 기준 영양값 환산과 합산 |
| `web/js/adapter.js` | 브라우저 저장소에서 회원·식단 조회와 변경, 데모 로그인 |
| `web/data/` | 음식 5,789건, 가상 회원 2명, 식단 42건 |

회원과 식단은 사이트 주소별 `localStorage`, 로그인 상태는 현재 탭의 `sessionStorage`에 보관합니다. 비밀번호는 브라우저의 Web Crypto API로 해시를 대조합니다.

## 테스트

Node.js 22 이상에서 테스트를 실행합니다.

```powershell
node --test web/test/*.test.js
```

음식 검색, g·mL 영양값 계산, 데모 로그인, 회원과 식단 관리, 다시 열었을 때의 기록 복구를 확인합니다.
