# 냠냠코치 · 음식 검색과 섭취 분석

PJT1에서 만든 Java 콘솔과 JSON 저장 방식을 이어받아 자료구조, 탐색, 정렬을 적용했습니다. 음식 목록을 순회하던 식품코드 조회에 `HashMap`을 사용하고, 이름의 시작 부분을 찾는 이진 탐색을 추가했습니다. 하루 분석에서는 같은 음식의 섭취 열량을 합산해 열량이 큰 순으로 보여 줍니다.

## 주요 기능

- 회원가입, 로그인·로그아웃, 본인 프로필 조회·수정, 탈퇴
- 음식 이름·식품코드 검색과 이름 시작 부분 검색
- 식단 작성·목록·상세 조회·수정·삭제, 음식별 g·mL 입력
- 한 끼와 하루 영양 합계, 같은 음식의 섭취 열량 합산 및 순위

## 실행

JDK 17 이상에서 Maven Wrapper로 실행합니다.

```powershell
cd pjt2
.\mvnw.cmd compile exec:java
```

macOS와 Linux에서는 `sh ./mvnw compile exec:java`를 실행합니다. 첫 실행에는 `demo01` / `DemoMeal01!` 또는 `demo02` / `DemoMeal02!`로 로그인할 수 있습니다.

| 메뉴 | 사용 방법 |
| --- | --- |
| `3 음식 검색` | 이름에 들어 있는 단어 또는 식품코드를 입력합니다. |
| `14 이름 시작 검색` | `현미밥`처럼 음식명의 앞부분을 입력합니다. |
| `9 하루 분석` | 로그인 후 `2025-04-21`을 입력하면 날짜별 합계와 순위를 확인할 수 있습니다. |

## 자료구조와 알고리즘

| 작업 | 구현 | 비용 |
| --- | --- | --- |
| 회원·식단 저장 | 회원 ID와 식단 ID를 키로 하는 `LinkedHashMap`으로 관리합니다. | ID 조회 평균 `O(1)` |
| 식품코드 조회 | 음식 목록을 읽을 때 `HashMap`을 만들어 식단 작성과 영양 분석에서 사용합니다. | 목록 순회 `O(N)`에서 평균 `O(1)`로 개선. 인덱스 공간 `O(N)` |
| 이름 시작 검색 | 이름으로 미리 정렬하고, 이진 탐색으로 검색어보다 작지 않은 첫 위치를 찾은 뒤 일치하는 음식을 읽습니다. | 정렬 `O(N log N)`, 시작 검색 `O(log N + R)` |
| 하루 섭취 분석 | 음식 기준량에 맞춰 기록을 환산하며, 같은 식품코드끼리 섭취 열량을 더합니다. 음식별 합계를 열량 내림차순으로 정렬하고 동률은 코드순으로 표시합니다. | 날짜별 기록을 가져온 뒤 평균 `O(M + U log U)`, 추가 공간 `O(U)` |

`N`은 전체 음식 수, `R`은 일치한 검색 결과 수, `M`은 해당 날짜의 음식 기록 수, `U`는 해당 날짜에 먹은 서로 다른 음식 수입니다. 이름의 중간에 있는 단어를 찾는 메뉴는 목록을 순회합니다.

## 데이터와 저장

[초기 JSON](src/main/resources/data)에는 식품 영양성분 자료에서 추출한 음식 5,789건과 가상 회원 2명, 식단 42건이 들어 있습니다. 각 음식의 100g 또는 100mL 기준량으로 실제 섭취값을 계산하며, 원본 영양값에 기록된 0도 계산에 사용합니다. 회원과 식단 변경은 `pjt2/runtime/state.json`에 저장합니다.

## 검증과 성능 비교

```powershell
.\mvnw.cmd test
.\mvnw.cmd compile exec:java '-Dexec.mainClass=dev.yamyam.console.Benchmark'
```

테스트는 카탈로그의 식품코드 조회, 접두어 검색과 목록 순회의 결과 일치, g·mL 섭취량 환산, 같은 음식 합산, 회원별 식단 접근과 저장 후 재실행을 확인합니다.

벤치마크는 실제 음식 5,789건에서 동일한 식품코드 조회 5,000회를 만들고 목록 순회와 `HashMap`을 비교합니다. 워밍업 후 각 방법을 다섯 번 실행해 중앙값을 기록하고 매회 체크섬을 대조합니다. Windows의 JDK 25에서 목록 순회 **99.124ms**, `HashMap` 조회 **0.502ms**가 관측됐습니다. JSON 읽기·검증·인덱스 생성을 포함한 카탈로그 초기화는 **177.729ms**였으며 조회 측정과 별도로 기록했습니다.
