# 냠냠코치 · Yamyam Coach

냠냠코치는 먹은 음식을 기록하고 하루의 영양 섭취량을 확인하는 식단 관리 서비스입니다. 음식 이름이나 식품코드로 메뉴를 찾고, 실제로 먹은 양을 g 또는 mL로 입력하면 열량·탄수화물·단백질·지방이 계산됩니다. 회원마다 자신의 식단을 작성하고 지난 기록을 조회·수정·삭제할 수 있습니다.

Java 콘솔에서 첫 버전을 만든 뒤 검색, 화면, 서버, 저장 방식을 차례로 발전시켰습니다. 같은 식단 관리 기능이 새로 익힌 기술을 적용할 때마다 어떻게 바뀌었는지 각 버전의 코드로 확인할 수 있습니다.

## 개발 흐름

### 콘솔에서 식단을 기록하고 검색하기

Java 기본 문법과 객체지향, 컬렉션, 파일 입출력을 익힌 뒤 회원과 식단을 JSON에 저장하는 콘솔 프로그램을 만들었습니다. 이후 자료구조와 탐색·정렬을 적용해 식품코드를 `HashMap`으로 조회하고, 이름의 시작 부분을 이진 탐색으로 찾도록 개선했습니다. 하루 분석에도 음식별 섭취 열량 순위를 추가했습니다. [PJT1 · Java 콘솔](pjt1/) · [PJT2 · 검색과 분석 개선](pjt2/)

### 브라우저에 화면을 만들고 서버에 연결하기

콘솔 메뉴에서 하던 검색과 기록을 HTML 폼, CSS, JavaScript로 구현하고 회원·식단 데이터를 브라우저에 저장했습니다. 웹 서버를 다루는 단계에서는 이 화면을 JSP로 옮기고 Java 서비스와 연결했습니다. 외부 Tomcat에서 Servlet이 요청을 받아 입력을 검증하고, 서버가 로그인 세션과 식단 기록을 관리하게 됐습니다. [PJT3 · 브라우저 화면](pjt3/) · [PJT4 · Servlet과 JSP](pjt4/)

### MySQL로 저장하고 REST API로 제공하기

서버에서 JSON 파일로 관리하던 회원·음식·식단을 관계형 테이블로 설계하고 JDBC로 연결했습니다. 식단과 구성 음식을 한 트랜잭션에서 저장하도록 바꿨습니다. 마지막 단계에서는 이 데이터 모델을 이어받아 Spring Boot에서 JSON API를 제공하고, 조회 조건과 SQL은 MyBatis 매퍼 XML로 옮겼습니다. 회원과 식단 관리, 음식 검색, 하루 영양 분석을 Swagger에서 호출할 수 있습니다. [PJT5 · MySQL과 JDBC](pjt5/) · [PJT7 · Spring Boot REST API](pjt7/)

## 실행해 보기

브라우저에서 식단 기록 화면을 먼저 보려면 Python 정적 서버로 PJT3를 실행합니다. 최종 API는 JDK 17 이상과 MySQL 8.4에서 PJT7을 실행한 뒤 Swagger UI에서 확인할 수 있습니다. 각 버전의 실행 방법과 테스트는 해당 README에 있습니다. [PJT3 실행](pjt3/README.md#실행) · [PJT7 실행](pjt7/README.md#실행) · [Swagger UI](http://127.0.0.1:8077/swagger-ui/index.html)

## 데이터와 검증

각 버전에는 100g 또는 100mL 기준의 음식 영양 데이터 5,789건, 가상 회원 2명, 2025년 4월 21~27일의 데모 식단 42건이 들어 있습니다. 콘솔·브라우저·Servlet 버전에서는 JSON을, MySQL 버전에서는 초기화 SQL을 사용합니다. 회원과 식단 변경은 버전별로 저장됩니다. [데이터 출처와 외부 구성요소](THIRD_PARTY_NOTICES.md)

Java·JavaScript 테스트와 MySQL 연동 테스트의 실행 설정은 GitHub Actions에 있습니다. 단계별 README에는 검증 범위와 직접 확인할 수 있는 데모 절차를 정리했습니다. [검증 워크플로](.github/workflows/verify.yml)
